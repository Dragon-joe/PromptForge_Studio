# PromptForge Studio v2 User Guide

**Made by Shark**

## 1. Start the application

Run `start_windows.bat` on Windows or `start_linux.sh` on Linux/macOS, then open `http://127.0.0.1:5500`.

The application is fully local and requires no backend or API.

## 2. Build a prompt

1. Choose the task, target output, source and prompt depth.
2. Add a clear title, final objective and audience.
3. Choose the correct content-fidelity mode.
4. Configure language, organization, page, typography and visual identity.
5. Enable only useful learning boxes, diagrams and question types.
6. Add prohibited actions and one custom rule per line.
7. Review quality, conflicts and missing-element suggestions.
8. Copy, download or save the prompt.

## 3. Content-fidelity modes

- Strict Preservation
- Formatting Only
- Light Editing
- Study Guide Mode
- Intelligent Enhancement
- Full Rewrite

Use strict modes for source fidelity and enhancement or rewrite modes when new wording or labelled learning aids are required.

## 4. Projects and versions

Saving a new prompt creates a local project. Saving an existing project adds a version. The application retains up to 30 versions per project.

Projects can be previewed, opened, duplicated, exported or deleted.

## 5. Backup

Export a JSON backup from the Projects page. It contains settings, projects, versions, custom snippets, favorites and the current draft.

## 6. Privacy

No backend, API, cloud upload or external analytics are used. Data remains inside the current browser profile.

## 7. Keyboard shortcuts

- `Ctrl + K`: command search
- `Ctrl + S`: save project
- `Ctrl + Enter`: refresh prompt
- `G`: open builder
- `Esc`: close dialogs
