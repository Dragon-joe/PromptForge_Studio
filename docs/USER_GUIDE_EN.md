# PromptForge Nexus Studio v5 User Guide

**Made by Shark**

## 1. Start the application

Run `start_windows.bat` on Windows or `start_linux.sh` on Linux/macOS, then open `http://127.0.0.1:5500`.

The application is fully local and requires no backend or API.

## 2. Build a prompt

1. Choose the target model, reasoning level and execution mode.
2. Choose the task, target output, source and prompt depth.
3. Add a clear title, final objective and audience.
4. Choose the correct content-fidelity mode.
5. Configure language, organization, page, typography and visual identity.
6. Enable only useful learning boxes, diagrams and question types.
7. Add prohibited actions and one custom rule per line.
8. Review quality, conflicts and missing-element suggestions.
9. Copy, download or save the prompt.

The **Setup completion** bar scores the five builder steps and points to the first incomplete area. Use **Previous** and **Next**, then **Review output** on step five to move directly to the live preview.

The preview shows live word, character and approximate token counts before you copy or export the prompt.

## 3. Content-fidelity modes

- Strict Preservation
- Formatting Only
- Light Editing
- Study Guide Mode
- Intelligent Enhancement
- Full Rewrite

Use strict modes for source fidelity and enhancement or rewrite modes when new wording or labelled learning aids are required.

## 4. Projects and versions

Saving a new prompt creates a local project. Saving an existing project adds a version. The application retains up to 30 versions per project.

Projects can be previewed, opened, duplicated, exported or deleted.

## 5. Backup

Export a JSON backup from the Projects page. It contains settings, projects, versions, custom snippets, favorites and the current draft.

## 6. Privacy

No backend, API, cloud upload or external analytics are used. Data remains inside the current browser profile.

## 7. Keyboard shortcuts

- `Ctrl + K`: command search
- `Ctrl + S`: save project
- `Ctrl + Enter`: refresh prompt
- `G`: open builder
- `Esc`: close dialogs


## 13. Model targeting

- **GPT-5.6 Sol:** default profile for complex, quality-first work.
- **GPT-5.6 Terra:** strong balance of capability, speed and cost.
- **GPT-5.6 Luna:** efficient profile for well-defined high-volume work.
- Claude, Gemini, Grok and Universal profiles are also included.
- Reasoning choices adapt to the selected profile.
- Execution modes add a workflow for documents, research, coding, agentic work or creative production.

These settings only compile the prompt locally; no content is sent to any provider.


## Nexus UI Themes

Choose Aurora, Midnight, Ember, Forest, Royal, or Graphite from the top-bar Theme Center or the full Theme Studio in Settings. Every theme supports Auto, Light, and Dark modes, and the selection is stored locally.
