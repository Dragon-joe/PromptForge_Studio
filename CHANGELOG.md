# Changelog

## 5.0.0 — Guided Workflow Rebuild

- Added a five-step completion meter with contextual guidance and previous/next controls.
- Added live word, character, and approximate token statistics.
- Added four production templates for external-book authoring, scientific figure translation, repository rebuilds, and data matching.
- Improved Arabic/English command search with normalized matching and ranked results.
- Added accessible tab semantics, roving keyboard focus, dialog focus trapping, skip navigation, reduced-motion support, and forced-color support.
- Added installable-app prompting, visible Service Worker update handling, and addressable view hashes.
- Refined desktop and mobile layouts, including four-column output actions and sticky mobile step navigation.
- Expanded automated validation for the v5 workflow, accessibility structure, templates, and cache alignment.

## 4.1.0

- Replaced the single additive quality formula with a four-dimension readiness score: completeness, clarity, consistency, and specificity.
- Expanded conflict detection with normalized Arabic/English semantic phrase matching and additional conflict families.
- Added Builder Undo/Redo controls and Ctrl+Z, Ctrl+Shift+Z, and Ctrl+Y shortcuts with a 40-state history.
- Expanded project search across title, goal, audience, prompt, rules, features, model, source type, and output format.
- Added a five-step first-run onboarding flow and a reusable Quick Tour button.
- Added visual score breakdown bars and supporting responsive styles.

## 4.1.0 — Nexus UI Edition
- Completely redesigned application shell, navigation, top bar, dashboard, cards, forms, builder, and responsive behavior.
- Added six complete interface themes: Aurora, Midnight, Ember, Forest, Royal, and Graphite.
- Added Auto, Light, and Dark modes for every theme.
- Added a quick Theme Center in the top bar and a full Theme Studio in Settings.
- Theme selection is saved locally and restored automatically.
- Preserved all prompt-building, projects, templates, snippets, backup, and offline functionality.

# 3.0.0 — Frontier Model Edition

- Added GPT-5.6 Sol as the default target model.
- Added 10 model profiles, adaptive reasoning choices and seven execution modes.
- Added model-aware prompt compilation and project persistence.
- Added a model profile card and default model setting.
- Isolated v3 local storage under the `pfs3_` namespace.
- Updated documentation, offline cache and validation metadata.
