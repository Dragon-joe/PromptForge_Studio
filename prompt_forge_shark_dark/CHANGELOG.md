# Changelog

## 2.4.0 — Dark Mode Rebuild

- Rebuilt the dark palette with layered navy surfaces and softer borders.
- Improved contrast for headings, body text, muted text, inputs, buttons, tabs, cards, and navigation.
- Added dark-specific states for selected controls, status badges, analysis messages, and save indicators.
- Refined the dashboard hero, floating prompt cards, metrics, quick templates, and recent-project panels.
- Improved the Builder live preview, output modes, code panel, forms, score chip, and action bar.
- Fixed dark rendering across Templates, Snippets, Projects, Guide, Settings, Maintenance, dialogs, and About.
- Fixed the privacy banner and range control styling in dark settings.
- Added consistent dark scrollbars and polished the mobile dark layout.
- Synced browser theme color and native control color scheme with the active theme.
- Updated application, cache, sidebar, About, package, and documentation versions to 2.4.

## 2.3.0 — Refined Theme

- Rebuilt the visual hierarchy across the dashboard, builder, templates, projects, guide, settings, maintenance, and About pages.
- Introduced a cleaner academic-blue system with calmer surfaces, stronger contrast, and consistent spacing.
- Refined the sidebar, top bar, buttons, inputs, cards, metrics, dialogs, and prompt output panel.
- Improved light and dark themes while keeping the user-selected accent color fully functional.
- Fixed mobile hero and dashboard grid behavior in RTL and LTR layouts.
- Removed horizontal overflow on desktop and mobile.
- Improved focus states, selected controls, form readability, and compact mode.
- Updated application, cache, sidebar, and About version labels to 2.3.
- Added explicit button types across the HTML for safer behavior.

## 2.2.0 — Reliability

- Hardened local storage, imports, versions, synchronization, cache updates, and responsive behavior.

## 2.0.0 — Local-first Rebuild

- Removed backend and API components.
- Added local projects, templates, snippets, quality analysis, conflict detection, bilingual support, and offline use.
