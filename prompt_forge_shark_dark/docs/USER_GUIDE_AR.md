# دليل استخدام PromptForge Studio v2

**Made by Shark**

## 1. تشغيل الموقع

1. فك ضغط المشروع.
2. شغّل `start_windows.bat` على Windows أو `start_linux.sh` على Linux/macOS.
3. افتح `http://127.0.0.1:5500`.

الموقع يعمل محليًا بالكامل ولا يحتاج Backend أو API.

## 2. إنشاء Prompt جديد

1. افتح **منشئ Prompt**.
2. في تبويب **الهدف** حدد نوع المهمة، الملف المطلوب، نوع المصدر ومستوى التفاصيل.
3. اكتب عنوانًا واضحًا ونتيجة نهائية محددة والجمهور المستهدف.
4. في تبويب **المحتوى** حدد مستوى الحفاظ على النص ونظام اللغة والتنظيم.
5. في تبويب **التصميم** اضبط المقاس والهوامش والخطوط والألوان وخصائص الملف.
6. في تبويب **التعليم** اختر الصناديق والرسومات والأسئلة المفيدة فقط.
7. في تبويب **القواعد** أضف الممنوعات والتعليمات الخاصة.

تتحدث المعاينة ودرجة الجودة والتعارضات تلقائيًا.

## 3. أوضاع الحفاظ على المحتوى

- **حفظ كامل 100%:** لا تغير الكلمات؛ استخدمه للتنسيق الأكاديمي الدقيق.
- **تنسيق فقط:** إصلاح الشكل والهيكل بدون إعادة صياغة.
- **تحرير خفيف:** يسمح بإصلاح OCR والأخطاء الواضحة.
- **دليل المذاكرة:** تنظيم وشرح مع الحفاظ على المعنى.
- **تحسين ذكي:** يسمح بإضافات تعليمية واضحة ومنفصلة.
- **إعادة كتابة كاملة:** لإنشاء نسخة جديدة تحافظ على الفكرة والنبرة.

## 4. كشف التعارضات

يعرض المحرك تنبيهًا عندما تكون التعليمات غير متوافقة، مثل:

- الحفاظ على كل كلمة مع طلب التلخيص.
- اختيار PowerPoint لمهمة قالب Word.
- منع المعلومات الخارجية مع طلب الإضافة من الخبرة.
- طلب PDF مع اشتراط قابلية تعديل Word الكاملة.

لا يمنع التنبيه إنشاء الـPrompt، لكنه يوضح التعديل المطلوب.

## 5. مكتبة القوالب

- استخدم البحث أو التصنيف للوصول إلى القالب.
- اضغط النجمة لحفظ القالب في المفضلة.
- اضغط **استخدام القالب** لتحميل الإعدادات في المنشئ.
- كل إعداد بعد التحميل يظل قابلًا للتغيير.

## 6. المقاطع الذكية

المقاطع هي قواعد متكررة مثل مراجعة الجودة أو منع التخمين.

- المقاطع المدمجة لا يمكن حذفها.
- يمكنك إنشاء مقاطع خاصة وتعديلها وحذفها.
- زر **إضافة** يضع المقطع داخل التعليمات المخصصة.

## 7. المشاريع والإصدارات

عند حفظ مشروع جديد، يتم إنشاء سجل محلي. عند حفظ المشروع نفسه مرة أخرى، تتم إضافة نسخة جديدة إلى سجل الإصدارات.

الإجراءات المتاحة:

- معاينة الـPrompt.
- فتح المشروع في المنشئ.
- إنشاء نسخة مستقلة.
- تصدير المشروع كملف JSON.
- حذف المشروع وإصداراته.

يحتفظ النظام بآخر 30 إصدارًا لكل مشروع للحفاظ على الأداء.

## 8. النسخ الاحتياطي

من صفحة **المشاريع والإصدارات**:

- **تصدير نسخة احتياطية:** ينزّل الإعدادات والمشاريع والمقاطع والمفضلة والمسودة في ملف JSON.
- **استيراد:** يعيد البيانات من ملف احتياطي صالح.

صدّر نسخة قبل مسح بيانات المتصفح أو تغيير الجهاز.

## 9. الإعدادات

يمكن تعديل:

- لغة الواجهة العربية أو الإنجليزية.
- الوضع الفاتح أو الداكن أو نظام الجهاز.
- كثافة وحجم الواجهة.
- اللون الرئيسي.
- مستوى الـPrompt الافتراضي.
- الحفظ التلقائي والمعاينة المباشرة.
- دمج السطور المتكررة.
- اختصارات لوحة المفاتيح.
- صيغة التنزيل واسم الملف.

## 10. اختصارات لوحة المفاتيح

- `Ctrl + K`: البحث السريع والأوامر.
- `Ctrl + S`: حفظ المشروع.
- `Ctrl + Enter`: تحديث الـPrompt.
- `G`: فتح المنشئ عندما لا تكون داخل حقل كتابة.
- `Esc`: إغلاق البحث أو النوافذ.

## 11. الصيانة

صفحة الصيانة تفحص:

- LocalStorage.
- النسخ إلى الحافظة.
- تنزيل الملفات.
- Service Worker وCache.
- معالجة JSON.

وتوفر:

- إصلاح عناصر التخزين التالفة.
- استعادة الإعدادات الافتراضية.
- مسح Cache لتحديث نسخة الموقع.
- تنزيل تقرير تشخيص JSON.

## 12. الخصوصية

- لا يوجد Backend.
- لا يوجد API.
- لا يوجد تخزين سحابي.
- لا يتم إرسال محتوى الـPrompt لأي جهة.
- البيانات محفوظة داخل بروفايل المتصفح المستخدم.

على الأجهزة المشتركة، صدّر نسخة احتياطية ثم امسح البيانات المحلية عند الانتهاء.
