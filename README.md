# PromptForge Nexus Studio 5.0 — Guided Workflow Edition

منصة Frontend مستقلة لبناء Custom Prompts احترافية لملفات Word وPDF وPowerPoint والمحتوى التعليمي.

## Nexus UI 5.0

النسخة الخامسة تعيد تنظيم تجربة العمل نفسها، وليس مجرد تغيير الألوان:

- Sidebar عائم جديد.
- Topbar زجاجي عائم.
- Bento Dashboard جديدة.
- إعادة تصميم منشئ الـPrompt والمعاينة والقوالب والمشاريع والإعدادات.
- تحسين كامل للموبايل والاستجابة للشاشات المختلفة.
- حركات وانتقالات أخف وأوضح.
- مسار إرشادي من 5 خطوات مع نسبة اكتمال ومؤشر للنواقص.
- إحصاءات مباشرة لعدد الكلمات والحروف والـTokens التقديرية.
- تنقّل كامل بالكيبورد، Focus واضح، وحماية تركيز النوافذ المنبثقة.
- روابط داخلية لكل صفحة، بحث عربي مُطبّع، وتحديث PWA واضح للمستخدم.

## الثيمات

يتوفر 6 ثيمات كاملة:

1. **Aurora** — أزرق وبنفسجي.
2. **Midnight** — كحلي وسماوي.
3. **Ember** — برتقالي ودافئ.
4. **Forest** — أخضر وهادئ.
5. **Royal** — بنفسجي وذهبي.
6. **Graphite** — رمادي Minimal.

كل ثيم يدعم:

- **Auto** حسب نظام الجهاز.
- **Light**.
- **Dark**.

يمكن تغيير الثيم بسرعة من **Theme Center** في الشريط العلوي أو من **Theme Studio** داخل الإعدادات. الاختيار محفوظ محليًا.

## ملفات الموديلات

- ملف مخصص افتراضيًا لـ **GPT-5.6 Sol**.
- 10 ملفات موديلات قوية: GPT-5.6 Sol / Terra / Luna، Claude، Gemini، Grok، وUniversal.
- اختيار مستوى التفكير حسب كل موديل.
- 7 أنماط تنفيذ: مستندات، مباشر، عمل عميق، Agentic، بحث، برمجة، وإبداع.
- حقن تعليمات تحسين خاصة بالموديل داخل الـPrompt تلقائيًا.
- حفظ الموديل ومستوى التفكير ونمط التنفيذ داخل المشاريع والإصدارات والنسخ الاحتياطية.

## الخصوصية

- لا يوجد Backend.
- لا يوجد API.
- لا توجد تحليلات خارجية.
- لا يتم إرسال محتوى الـPrompt إلى الإنترنت.
- التخزين يتم داخل LocalStorage في المتصفح.

## الوظائف

- معاينة مباشرة للـPrompt.
- تقييم جودة من 100.
- كشف تعارضات واقتراح العناصر الناقصة.
- 16 قالبًا احترافيًا قابلاً للتخصيص، تشمل تأليف الكتب الخارجية، ترجمة الرسومات العلمية، إعادة بناء المشاريع، ومطابقة البيانات.
- مكتبة مفضلة وبحث وتصنيفات.
- مقاطع ذكية قابلة للحفظ وإعادة الاستخدام.
- مشاريع مع سجل إصدارات محلي.
- تصدير واستيراد نسخة احتياطية JSON.
- واجهة عربية وإنجليزية.
- اختصارات لوحة مفاتيح وبحث سريع `Ctrl + K`.
- Service Worker للعمل دون اتصال.
- دليل استخدام وصيانة وتشخيص داخل الموقع.
