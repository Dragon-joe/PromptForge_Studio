# PromptForge Studio 2.4 — Made by Shark

منصة Frontend مستقلة لبناء Custom Prompts احترافية لملفات Word وPDF وPowerPoint والمحتوى التعليمي.

## أهم التغييرات

- إزالة Backend وAPI وقاعدة البيانات بالكامل.
- تخزين محلي داخل المتصفح فقط.
- واجهة جديدة أكثر تنظيمًا وسرعة واستجابة.
- معاينة مباشرة للـPrompt.
- تقييم جودة من 100.
- كشف تعارضات واقتراح العناصر الناقصة.
- 12 قالبًا احترافيًا قابلاً للتخصيص.
- مكتبة مفضلة وبحث وتصنيفات.
- مقاطع ذكية قابلة للحفظ وإعادة الاستخدام.
- مشاريع مع سجل إصدارات محلي.
- تصدير واستيراد نسخة احتياطية JSON.
- إعدادات عربية وإنجليزية وثيم فاتح/داكن.
- اختصارات لوحة مفاتيح وبحث سريع `Ctrl + K`.
- Service Worker للعمل دون اتصال.
- دليل استخدام وصيانة وتشخيص داخل الموقع.
- صفحة About تحمل عبارة `Made by Shark`.


## تحديث الوضع الداكن 2.4

- إعادة بناء ألوان الوضع الداكن بدل عكس ألوان الوضع الفاتح.
- فصل واضح بين خلفية الصفحة والكروت والحقول والمناطق التفاعلية.
- تقليل حدة الحدود البيضاء والظلال الزائدة.
- تحسين قراءة النصوص الثانوية والعناوين والبيانات داخل الكروت.
- إصلاح ألوان الحقول والقوائم وحالات التركيز والـPlaceholder.
- إصلاح حالات الاختيار والتبويبات والشارات والتنبيهات.
- تحسين لوحة المعاينة، صناديق التحليل، النوافذ المنبثقة ودليل الاستخدام.
- إصلاح بطاقة الخصوصية وشريط حجم الواجهة داخل الإعدادات.

- تحديث لون واجهة المتصفح تلقائيًا عند تفعيل الوضع الداكن.

## التقنيات

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage
- Service Worker / Cache API
- Web App Manifest

لا توجد مكتبات خارجية أو اتصالات بخادم.

## التشغيل

### Windows

شغّل:

```text
start_windows.bat
```

ثم افتح:

```text
http://127.0.0.1:5500
```

### Linux / macOS

```bash
./start_linux.sh
```

أو:

```bash
python3 -m http.server 5500
```

يمكن فتح `index.html` مباشرة، لكن بعض المتصفحات لا تفعّل Service Worker والنسخ المتقدم عند استخدام `file://`.

## الخصوصية

- لا يوجد تسجيل دخول.
- لا يوجد رفع ملفات أو Prompts.
- لا توجد تحليلات خارجية.
- المشاريع والإعدادات تحفظ في `LocalStorage` داخل بروفايل المتصفح الحالي.
- مسح بيانات المتصفح يحذف المشاريع؛ استخدم النسخ الاحتياطي من صفحة المشاريع.

## التحقق

```bash
npm run check
```

يفحص صياغة JavaScript، العناصر الأساسية، عدد القوالب، وعدم وجود ملفات Backend أو مراجع لخدمات الخادم القديمة.
